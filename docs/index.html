Find, create and share your own.

Dozens of Hugging Face models already run on Loom, each one checked against llama.cpp on the same weights. Porting your own is one prompt with loom-skills: point your agent at a GGUF and it builds, tests and benchmarks the port on Loom for you.

  1. Step 1install

    Add loom-skills to Claude Code, Codex or Pi. The skills install Loom (hrx-loom, from ROCm/hrx-system) themselves.

    $ npx skills add loom-fun/loom-skills --skill '*' -g
  2. Step 2port

    Ask your agent to port, validate and optimize any GGUF model.

    > /loom get <org>/<model> working on loom-serve, optimize it, and report the performance relative to llamacpp rocm
  3. Step 3publish

    Generate the card from the benchmark report and upload the package to Hugging Face.

    $ hf upload <hf-org>/<model>-loom PKG .
