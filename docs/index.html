hrx-loom

Loom: Model optimization is no longer locked by the engine.
Experimental dev preview.

hrx-loom is a new end-to-end stack (compiler, runtime and serving tools) that lets anyone write, optimize, serve and share kernels and models without modifying the inference engine or the server.

Kernels are written in .loom files, a vector programming model reminiscent of MLIR that is easy for agents. To show what the stack can do early on, we ported 50+ models as an experiment, and you can fetch and serve them today.

  • ROCm/hrx-system ↗Loom compiler and server
  • loom-fun/loom-skills ↗agent skills to port and optimize
  • huggingface.co/loom-fun ↗kernels for the 50+ ported models
  1. Step 1Install

    Install hrx-loom from PyPI.

    $ pip install "hrx-loom[hf]==0.1.0"
  2. Step 2Fetch

    Pull a Loom model from Hugging Face.

    $ loom-fetch https://huggingface.co/loom-fun/unsloth-Qwen3-0.6B-loom/resolve/main/model.json --output=qwen3-0.6b
  3. Step 3Serve

    Start a local OpenAI-compatible server.

    $ loom-serve --device=amdgpu --model=qwen3-0.6b/model.json

05 / set free

Model optimization has been set free.

Historically, supporting a new model meant changing the inference engine first. Every new architecture or kernel had to wait on engine work, which slowed everyone down and left the community dependent on a small group of maintainers. With Loom, models and kernels live outside the engine: anyone can port, optimize and share a model without touching the runtime or the server.

A small SDK

The compiler, runtimes and devtools have no dependencies. Download them as a wheel or link them into your own application; they build from source in about a minute and would still fit on a few floppy disks.

Many targets

One stack targets x86, AMD GPU, AMD NPU and generic Vulkan devices.

Standalone or embedded

Run it as an inference server with loom-serve, or plug it into existing engines, like the experimental HRX backend for llama.cpp.

Tell us what you need

We're still learning how the community will use and deploy new inference stacks, so we'd love your feedback. Open an issue on hrx-system or loom-skills.
